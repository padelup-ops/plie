# GCompris pour iPhone, iPad et iPhone Duo (essai)

Portage expérimental de [GCompris](https://gcompris.net) (KDE, GPL) vers iOS avec Qt 6.
Rien n'est publié sur l'App Store sans l'accord de l'équipe GCompris.

- `patches/` : nos modifications, appliquées sur le code de GCompris au moment de la compilation.
- Workflow `gcios-sim.yml` : compilation pour le simulateur, captures sur la branche `ci-gcios-sim`.
