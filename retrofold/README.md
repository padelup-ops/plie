# RetroFold

A tactile 90s handheld console for iPhone Duo: pick a cartridge on the cover, unfold, play.

RetroFold is based on **Foldcade** by Eren Ergeç (https://github.com/ErenErgec/iPhone-Duo-Foldcade),
released under the MIT License (see `LICENSE`, kept as is). Upstream commit: see `UPSTREAM`.
Changes: name, bundle and product identifiers, icon, translations and store setup.
