RetroFold

Une console portable des années 90 pour iPhone Duo

Comment jouer

  1. Fermé : choisis une cartouche sur l’écran extérieur (fais-les défiler).
  2. Déplie ton iPhone Duo comme une console à clapet : l’écran au-dessus du pli, les commandes en dessous.
  3. Replie-le pour mettre en pause. Déplie pour reprendre.

Achat

Huit cartouches, tous les modes et toutes les palettes sont gratuits. RetroFold Pro est un achat unique, sans abonnement : quatre cartouches de plus, toutes les coques, les packs de sons et les écrans LCD, Trinitron et Arcade. Pour récupérer ton achat : Store → Restore Purchases.
