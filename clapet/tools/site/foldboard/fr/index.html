Foldboard

Le clavier fait pour l’iPhone Duo

Installer le clavier

  1. Ouvre l’app Foldboard et touche Ajouter le clavier, puis Ouvrir Réglages.
  2. Touche Claviers, active Foldboard, puis Autoriser l’accès complet (pour les vibrations, les sons et tes réglages).
  3. Dans n’importe quelle app, maintiens la touche globe 🌐 et choisis Foldboard.

Le clavier suit ta main

En mode « Suit ta main », Foldboard regarde comment le téléphone penche quand le clavier s’ouvre, puis ton pouce pendant que tu tapes. Tiens-le à deux mains sur le Duo ouvert : il se coupe en deux. Pour qu’il se trompe moins, étalonne-le dans l’app (Position et taille → Suivre ta main). Un balayage du pouce vers le haut sur les touches le fait venir de ton côté.

Essai et achat

Toutes les options sont gratuites pendant 3 jours, sans abonnement. Ensuite, Foldboard Pro est un achat unique. La frappe à une main, la pleine largeur, l’AZERTY et le QWERTY restent gratuits. Pour retrouver ton achat : écran Foldboard Pro → Restaurer les achats.
